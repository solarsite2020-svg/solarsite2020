Relation這個英文字具有關聯、關係、交情汁液；廣泛解釋在人與人之間，所指涉的是人情、倫理或與利害結合的一種複雜的溝通關係。在傳統理解中，個體存在之所以被肯定，乃由於此個體處於自身與外部世界的「關係網絡」之中，由此，主客體的座標方位才得以被確認與描述。反之，若在主客體模糊的當下，熟悉的座標系統是否可能因此而崩潰？

面對全球化與資訊化所造成的價值扁平化效應，現在人的生活夾雜在真實與虛擬之間，在真假互扣的世界裡，人們因此產生了一種個體與外界的新關係感。香港藝術家白雙全曾在《So close So far》的觀念藝術創作中，從半邊西瓜來聯想此種當代社會的人際關係，當你吃著購自超市的半邊西瓜時，其實正與陌生的另一家人分享著這個完整的水果。此種聯想真正呈現出在商業與物化的世界中，人與人之間既緊密卻又疏離的關係。

在此現象下，無論你喜不喜歡自己所處的世界，深陷其中都無法逃避而只能面對。《無關係的關係》的舞作，街次編舞者以其自身生存經驗的意識，透過洗鍊的藝術語言，表達人們對存在的指認、對幸福的想像以及對大環境的認知與反思。首先由團長視覺藝術家潘大謙的裝置藝術作品「閃燃」維續，而後透過藝術總監程曉嵐、旅美舞蹈家張崇富、駐團編舞者許慧玲、卓雅會，以及新生代編舞者蘇紹明等，共同完成五個章節的舞蹈動作，透過視覺畫面、肢體語彙和舞台結構，詮釋個體於感官網路中的存在狀態，整場演出無中場休息，一氣呵成。
