[ Bingo！]

常見於遊戲玩家歡呼勝利，
答對題目、尋獲目標，或終於想起失憶的事件，
甚而對某些舊有事物產生新的體悟，
此時Bingo皆具興奮之意。
[ Be ]  原形動詞，一切事物最基本的存在
[ In  ]  在..裡面
[ Go]  往前
2009《Bingo! B In Go》為索拉舞蹈空間第三季展演活動。索拉舞蹈空間自2005年成立以來，編舞者與舞者共同以行動串連(Be)，將舞團中創作的體現(In)，在展演主題標的下全然開放(Go)，期盼透過實踐的過程，發現生命的意義與藝術的價值(Bingo！)。
