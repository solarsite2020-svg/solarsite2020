藝術必須是修辭，因此藝術才成為可能；生活也是修辭，資訊使過剩的生活符碼變為零散的情緒與喃喃自語。

在這零散而喃喃自語的世界裡，當代生活如同一幅不可見的藍圖，裡面是一個平滑而流暢的時空，慾望流動無礙，在這裡，人們不斷地被過剩的事物填滿；政治娛樂、市井閒話、桃色新聞，以及許許多多「更值得了解的事」。但同時，這也是一個接近完全自由的時代。

人們需要愛，但也因為知道「愛」，因此感受到「過剩的愛」造成愛的缺失，好比人們看到一幅透視圖，卻無法看到透視法本身。人們在孤獨的時候感到不自在，所以要到人群中去，陌生的人群讓我們享受真正的孤獨，你會在路邊與櫥窗前遇到我們，似是而非，飄蕩閒逛，用溫柔的眼神穿越一切。屏幕在手中，訊息隨手可得，激情卻一無所知。

街道是室內，室內也是街道，色彩繽紛，大地充滿想像，其實一切卻單調如一。過剩的修辭使藝術消散了，過剩的生活修辭也使生活消散了。在這李，我們與我們的愛可以沐浴在空無烏有之中，我們的心冷靜而溫暖，慢慢道出一句話...「哪兒都可以，只要在離生活近一點」
