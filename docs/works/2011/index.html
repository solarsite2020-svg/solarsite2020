現代社會在全球化的步伐下以全面資本邏輯及秩序運作，「感覺良好」是生活在其中的人們對生命之詠嘆，同時亦是相對無奈的曖昧反諷。

全球網路與運輸科技的進步，一方面已經成為商品的生產與流通打造了前所未有的多元管道，另一方面在全球化劃一標準的物慾追求底蘊下，商品已透過媒體技術催生出藝術美化物質慾望的文化，這種文化也塑造了現代人在精緻官能被滿足的同時，生命隨之富足的價值意象。人們對消費的想像，以內化為對於幸福感為一個描述，加上數位化科技的參與，每一件事物的出現都彷彿是專屬自己特色的劇本，一切是如此完美。在虛擬空間中，認知介面透過與使用者互動，使用者琬茹擁有了自己的舞台，可以隨時即興演出，時間與空間跳脫了限制。一切價值、意識形態伴隨膨脹的資訊而變得輕薄。世界在繽紛色彩中向我們招手，而背後是否帶著幾分灰色的宿命？

一個場景：(傍晚時分)家人正在精緻的餐桌前用膳，豐盛的佳餚中，有產自越南的明蝦、澳洲的牛肉、美國黃豆製成的日本豆腐。電視新聞透過衛星訊號，正報導著伊拉克的戰爭，美國的軍人們在破敗的街道中搜索著敵人，受驚的婦女兒童瑟縮於一角。電視螢幕閃著搖晃不清的影像，與飯廳中柔和的燈光形成對比。我們一邊吃飯，一邊討論著油價的波動對明天股市的影響。一切如此熟悉，不協調卻又真實，我們在這個被資訊與物流異化了的暈眩世界裡，誰都無法逃脫。

「誰都無法逃脫」，正是索拉舞蹈空間2011年企圖透過舞蹈創作反芻這種存在的經驗。「感覺良好」醞釀在一切日常中最普通的事件中，或許是一場戀愛、一次購物、一場宴會、一次捷運上的手機通話...在資訊開放的世界裡，其實人們是自由的，但在生活被物化至如電腦般冷靜、又如廣告般熱鬧的同時，人們也被引進了孤獨的陷阱，我們是否正在用自由來消耗自由。

索拉舞蹈空間2011《感覺良好》演出計畫，編舞者將以日常作為觀察對象，從身體的觀點來閱讀生活，透過當代舞者的身體作為平台，表達人們對存在的指認、對幸福的想像以及對大環境的認知與反思。
