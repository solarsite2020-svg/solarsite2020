在現今這個被商業與物化的世界中
其實我們身處的環境像一部冷冰的機器
「效能管理、­勞動模式與異化的身體」
構成了當代思維的核心
在現今這個被商業與物化的世界中
其實我們身處的環境像一部冷冰的機器
「效能管理、­勞動模式與異化的身體」
構成了當代思維的核心
歐西打街在哪裡？我已忘了它的地理位置，也許在香港、紐約、或台北，我只能描述這是一條不太起眼的小街道，跟我們時常路過卻不願多撇一眼的小巷弄差不多。在我們熟悉的城市裡，這類接到不知凡幾。

在這條街上住著一群平凡人，街頭電器維修店的老闆終日蹲著埋首修理沾滿油污的舊馬達，街尾一個不太講中文的越南媽媽常抱著孩子在門前踱步，幾個小孩騎著腳踏車來回於街道兩頭。街的另一側，有間家庭代工製鞋店，鞋模子橫七豎八，卻好像從來沒有製造過一雙完整的鞋子。街道某處的樓上蓋了一個違建陽台，一位中年男子每天總會上去露台逗留一下，有時手扶欄杆站一回，有時斜靠花架，凝視街道失神。

歐西打街上的人憨憨地過著他們的生活，日子日復一日，也許是相對於拐個彎之後那充滿活力的城市景象，歐西打街上的人們只能算是既不精確又無明確目標地生活著。的確，歐西打街上的勞動沒有準確的效力架構與管理標準，勞動者沒有利益計算，更遑論速度與效率。於是，緩慢、細碎而連貫的生活成就了歐西打街上全部的內容。這樣的生活跟現代人期待的不同；在城市裡，人們一直相信憑著努力能夠邁向夢想，勞動的目標是應有的回報。但在歐西打街裡，勞動與效應的絕對意向性被取消了，這裡的生活隨時被偶發的片段事件打斷而成為另一番景緻，NG與徒勞在此不能稱為失敗。

歐西打街上的勞動其實對當代生活的適切性提出了疑問，在扁平的世界裡，人們提問「無效」的積極可能性。潘國靈在其城市學中引用德勒茲的話語：「游牧者並不離開，也不想離開，他執著於那片森林退縮後的平滑空間，那裡有草原或沙漠在進佔」。歐西打街上的人兒，用他們的徒勞，揭示出生在這平滑空間裡的另一種可能性。當大街上忙碌的人群訕笑著歐西打街裡人們的徒勞，或許，在那違建陽台上的男人正在想，忙碌的人們啊，你們像留在月球上的那面國旗一樣，最終將被浩瀚的宇宙射線漂白為沒有圖案的白旗。到底誰才在徒勞？

索拉舞蹈空間2014《歐西打街》是由潘大謙編導、程曉嵐與舞者們共同參與發展。我們虛擬了一條街道和一群平凡人的生活，以Outsider Alley為名，觀察並揣摩都會邊緣人們的生活片段，並將其徒勞的勞動轉化為劇場語言。在都市裡，效能管理、勞動模式與異化的身體構成了當代思維的核心，「歐西打街」裡的人們，用他們的徒勞，揭示出生在這平滑空間裡的另一種可能性，其無效的勞動及因徒勞而產生的細碎意象也許是最接近藝術本質的語言。
